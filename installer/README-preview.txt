ZACHAGOTCHI MAC FLASHER — PREVIEW

This preview does not contain device firmware and cannot flash a board.
Open the .app or .command to see the missing-firmware message. Use the full
release disk image to install Zachagotchi. No board backup is created.

The full installer opens Terminal, asks you to select a USB port and type
INSTALL, then erases all flash and installs Zachagotchi. The current program,
Wi-Fi settings and saved progress are deleted. There is no undo.

Native Intel and Apple Silicon tools are included; no Rosetta, Python, Homebrew
or Arduino installation is required. This personal build is not Developer ID
signed or notarized. It installs no system services or drivers.
